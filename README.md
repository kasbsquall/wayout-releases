# Wayout: instaladores

Aquí se publican solo los instaladores de Wayout para Windows y el archivo `latest.json` que la app consulta para saber si hay una versión nueva. El código de Wayout es cerrado y no está en este repositorio.

Descarga e información: https://wayout.avanc3.pe

Cada versión trae el instalador (`Wayout_<versión>_x64-setup.exe`) y su firma (`.sig`). La app solo instala una actualización si la firma corresponde a la clave pública que lleva dentro, así que un archivo cambiado por otra persona se rechaza.

Privacidad, términos y qué borra la app: https://wayout.avanc3.pe/privacidad/

# Wayout: installers

This repository only holds the Wayout installers for Windows and the `latest.json` file the app reads to find out whether a new version exists. Wayout is closed source; its code is not here.

Download and details: https://wayout.avanc3.pe/en/

Each release ships the installer (`Wayout_<version>_x64-setup.exe`) and its signature (`.sig`). The app only installs an update whose signature matches the public key built into it, so a file altered by someone else is rejected.

Privacy, terms and what the app deletes: https://wayout.avanc3.pe/en/privacy/
